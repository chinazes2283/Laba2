# Лабораторна робота №2

Тема: проєктування та реалізація об'єктно-орієнтованих систем в Python (класи, наслідування, композиція).

## Структура

```
.
├── lb2t1.py   # Завдання 1: ієрархія класів, наслідування, поліморфізм
├── lb2t2.py   # Завдання 2: інкапсуляція, property, name mangling
├── lb2t3.py   # Завдання 3: магічні методи, перевантаження операторів
├── lb2t4.py   # Завдання 4: абстрактні класи та композиція
├── lb2t5.py   # Завдання 5: паттерн проєктування
├── README.md
└── .gitignore
```

## Вимоги

- Python 3.10+
- Сторонні бібліотеки не використовуються (`requirements.txt` не потрібен)

## Запуск

Кожне завдання запускається окремо:

```bash
python lb2t1.py
python lb2t2.py
python lb2t3.py
python lb2t4.py
python lb2t5.py
```
